Citation details (who cited you)

Hover the ▲ change indicator on a publication to see which papers are the new citations. Google blocks automated access, so this drives your real Chrome — which needs a one-time Google sign-in. It runs hidden in the background; if Google ever shows a CAPTCHA, a window pops up so you can solve it once.
